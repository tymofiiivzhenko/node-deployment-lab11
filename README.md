# Deployment API Lab (Практична робота №11)

## Локальний запуск
1. Встановіть залежності: `npm ci`
2. Скопіюйте `.env.example` у `.env` та за потреби відредагуйте параметри (`PORT`, `NODE_ENV`, `APP_ENV`, `APP_MESSAGE`).
3. Запустіть сервер у режимі розроблення: `npm run dev`
4. Запуск тестів: `npm test`
